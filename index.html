사용법

  1. 카드를 클릭하면 오른쪽에 이름·내용·작업 근거가 표시됩니다.
  2. − / ＋ 로 확대·축소하고, 전체 보기로 한 화면에 맞춥니다.
  3. 항목 검색에 단어를 넣고 항목 찾기에서 고르면 해당 카드로 이동합니다.
  4. 카드를 더블클릭하면 하위 항목이 접히고 펼쳐집니다. 카드 아래 ＋ / − 표시로 상태를 알 수 있습니다. (내 화면에서만 적용)
  1. 카드를 클릭하고 오른쪽에서 이름과 내용을 입력하세요. 바로 반영됩니다.
  2. 카드를 더블클릭하면 하위 항목이 접히고 펼쳐집니다. 접힘 상태도 게시하면 열람자의 첫 화면에 반영됩니다.
  3. 하위 항목 / 같은 단계로 항목을 만들고, 항목 삭제로 지웁니다. 삭제는 실행 취소할 수 있습니다.
  4. 사진 추가로 여러 장을 넣고, 사진 아래에 설명을 기록하세요.
  5. 카드를 드래그하거나 자동 정렬로 배치하세요. 소속 변경으로 가지를 옮길 수 있습니다.
  6. 선을 클릭해 직선·곡선·직각, 실선·파선·점선, 화살표와 색상을 바꾸세요.
  7. 변경사항 게시를 누르면 GitHub 저장소의 data.json이 갱신되고, 1~2분 뒤 사이트에 반영됩니다. 게시 전 편집은 이 브라우저에만 암호화되어 임시 저장됩니다.
  8. 비밀번호 변경은 새 비밀번호로 다시 암호화해 게시합니다. 이후 사이트는 새 비밀번호로만 열립니다. (저장소 기록에 남은 예전 버전은 예전 비밀번호로 열리므로, 노출이 걱정되면 저장소를 새로 만드세요.)
  9. 편집 종료는 이 브라우저에 저장된 GitHub 토큰을 지웁니다.

Ctrl+S: 게시 · Ctrl+Z: 실행 취소 (입력창에서는 글자 편집)
